# Historial de Docker Compose

Esta carpeta contiene versiones anteriores del archivo `docker-compose.yml` del proyecto Rotborn Studios.

## Versiones

- **`docker-compose.yml.backup`**: versión inicial, con WordPress y MariaDB en una red común.
- **`docker-compose.yml.pre-nginx`**: incorpora redes públicas y privadas.
- **`docker-compose.yml`**: versión actual, con Nginx como proxy inverso y acceso HTTPS.

## Evolución

La configuración ha evolucionado para mejorar la organización de la red y añadir HTTPS mediante Nginx, manteniendo las bases de datos en la red privada.
